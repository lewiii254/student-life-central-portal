## 🚀 Quick Start Guide

### 📋 Prerequisites

Before you begin, ensure you have:
- 📱 **Node.js** (v18+ recommended)
- 📦 **npm** or **yarn** package manager
- 🌐 **Modern web browser**
- ☕ **A cup of coffee** (optional but recommended! ☕)

### ⚡ Installation

1. **Clone the repository**
   ```bash
   git clone <YOUR_GIT_URL>
   cd <YOUR_PROJECT_NAME>
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open your browser** 🌐
   Navigate to `http://localhost:8080` and start exploring!

## 🗄️ Database Schema

```mermaid
erDiagram
    AUTH_USERS ||--o{ ADMIN_USERS : "can be"

        string avatar_url
        timestamp created_at
    }
    
    ORDERS {
        uuid id PK
        string customer_name
        string customer_contact
        jsonb items

    }
    
    PRODUCTS {
        uuid id PK

        integer price
        integer stock_quantity
        string category
        boolean is_combo
    }
    
    RENTAL_REQUESTS {
        uuid id PK
        string name

        integer budget
        string status
        string assigned_agent
    }
    
    HOUSES {
        uuid id PK
        string title
        integer price
        string location
        string sub_area
        integer bedrooms
        string[] features
        string landlord_contact
        boolean available
    }
    
    BICYCLES {
        uuid id PK
        string name
        integer hourly_rate

        string status
    }

        uuid id PK
        uuid bicycle_id FK
        string customer_name
        string customer_contact
        timestamp rental_start
        timestamp rental_end
        integer total_cost
        string status
    }
    
    EVENTS {
        uuid id PK
        string title
        timestamp event_date
        integer ticket_price
        integer max_attendees
        string status
    }
    
    PARTNER_SHOPS {
        uuid id PK
        string name
        string location
        decimal commission_rate
        boolean active
    }
    
    HOUSEHOLD_ITEMS {
        uuid id PK
        uuid partner_shop_id FK
        string name
        integer price
        string condition
    }
    
    REFERRALS {
        uuid id PK
        uuid referrer_id FK
        uuid referred_user_id FK
        string referred_user_name
        string status
        decimal reward
    }
```
